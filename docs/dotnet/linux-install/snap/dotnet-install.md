!!! warning

    Make sure that you uninstall the old ***Snap Dotnet-Sdk*** before installing the Dotnet snap:
    ``` bash
    $ sudo snap remove dotnet-sdk
    ```

### 1. Install the .NET Snap :
---
``` bash
$ sudo snap install dotnet --classic
```

### 2. Install .NET 9 SDK :
---

This Will Install Both Sdk and Runtime.
``` bash
$ dotnet-installer install sdk 9.0
```
